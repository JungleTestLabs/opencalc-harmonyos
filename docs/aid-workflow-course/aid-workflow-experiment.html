aid-workflow 增量开发实验指南

4 步让 AI 帮你拆需求、写代码、做验证 — 单页快速上手
▎什么是 aid-workflow？
aid-workflow 是一套 AI 原生增量开发流程。把每次改动拆成可审查的独立增量，每个增量走完整的设计 → 实现 → 验证 → 归档闭环。
核心理念：每次改动都有 git diff + apply-report 自证，不只是"改好了你看吧"。
▎四阶段流程
1
PLANNING — 规划
  • rq-parse 需求解析
  • proposal / delta-spec
  • 复杂度判定 S/M/L/XL
  • 门控确认 → 下一阶段
2
IMPLEMENTING — 实施
  • 任务分解 tasks.md
  • 检查清单
  • 依赖分析
  • 门控确认 → 下一阶段
3
APPLYING — 应用
  • 代码生成 + 编译验证
  • git diff --stat 自证
  • apply-report 报告
  • 门控确认 → 下一阶段
4
ARCHIVING — 归档
  • 移动 change 目录
  • 归档到 archives/
  • 更新文档
  • 闭环完成 ✓
▎快速开始 — 动手实验
① 创建分支
git checkout -b feat/your-feature
② 写 proposal
用 rq-parse 解析需求 → proposal.md
③ 逐阶段执行
PLANNING → IMPLEMENTING → APPLYING → ARCHIVING
④ 查看报告
apply-report.md + git diff --stat
