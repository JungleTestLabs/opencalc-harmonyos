# Proposal: 单位换算功能

## 意图分类
- **类型**: requirement-add
- **领域**: 新功能 — 非标准计算（不属于四则运算和科学函数）
- **影响层次**: S（单一新模块 + UI 微调，不影响现有计算路径）

## 需求解析

用户输入含单位的表达式，系统自动识别并完成换算：
- "100cm to inch" / "100厘米转英寸" → 39.37 英寸
- "30C to F" / "30摄氏度转华氏度" → 86°F
- "5公里转英里" → 3.11 英里
- "1kg to lb" → 2.20 磅

## 设计方案

### 新增模块
- `converter/UnitConverter.ets`：单位识别 + 换算逻辑（独立模块，零侵入现有计算路径）

### UI 改动
- 在 ToggleRow 增加"换算"模式按钮（基础/科学/换算 三选一）
- 换算模式下：新增单位选择 UI（两行下拉选择器 + 数值输入）

### 关键决策
- **输入方式**：自然语言解析（"100cm to inch"），正则匹配模式
- **精度**：保留 2 位小数
- **错误处理**：不支持的组合 → "暂不支持该单位换算"

## 复杂度
**S 级**：单一新增文件 + CalculatorPage 微调（~30 行改动），无需架构变更。
