# Proposal: 小费计算器

## 意图分类
- **类型**: requirement-add
- **领域**: 新功能 — 消费场景计算（不属于四则运算和科学函数）
- **影响层次**: S（单一新模块 + UI 微调，不影响现有计算路径）

## 需求解析

用户输入总金额和人数，自动计算每人应付金额（含小费比例）：
- 输入金额 200、人数 4、小费 15% → 每人应付 57.50
- 输入金额 88、人数 2、小费 10% → 每人应付 48.40
- 支持快速选择常用小费比例（10%、15%、18%、20%）
- 支持自定义小费比例

## 设计方案

### 新增模块
- `converter/TipCalculator.ets`：小费计算逻辑（独立模块，零侵入现有计算路径）

### UI 改动
- 在 ToggleRow 增加"小费"模式按钮（基础/科学/历史/小费 四选一）
- 小费模式下：金额输入 + 人数输入 + 预设比例按钮 + 自定义%输入 + 结果展示

### 关键决策
- **输入方式**：TextInput 双字段（金额 + 人数）
- **比例选择**：4 个预设按钮（10%/15%/18%/20%）+ 自定义 TextInput
- **精度**：保留 2 位小数（Math.round(x * 100) / 100）
- **结果展示**：大字体人均金额 + 明细行（原始 + 小费 + 合计）
- **错误处理**：三层校验（金额>0、人数>0、比例>=0）

## 复杂度
**S 级**：单一新增文件 + CalculatorPage 条件渲染，无需架构变更。
