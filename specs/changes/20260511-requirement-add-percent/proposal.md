## 需求解析报告 (rq-parse)

### 原始需求
> "加一个百分号按钮，输入50+10%自动算出55"

### 意图分类
- **类型**：新增功能
- **一句话概括**：在计算器 UI 增加百分号(%)按钮，利用已有表达式引擎的百分比语义计算能力

### 领域映射
- **UI/交互**：在 CalculatorPage 按钮布局中增加 % 按钮
- **计算引擎**：Expression.ets 的 getPercentString() 已实现完整百分比逻辑（无需改动）

### 影响层次
| 层次 | 变更类型 | 说明 |
|------|---------|------|
| View | modify | CalculatorPage.ets 按钮布局增加 % 按钮 |
| ViewModel | - | 无需变更（Expression.ets 逻辑已就绪） |
| Model | - | 无需变更 |

### 关键实体
- 页面实体：CalculatorPage（按钮布局）
- 接口实体：Expression.getCleanExpression()（已有，不新增）

### 代码洞察（关键发现）
经检查 Expression.ets 第 222-246 行，`getPercentString()` **已实现**三种百分比语义：
```
A+B%  → A + A*(B/100)    (加法/减法的百分比叠加 — 第226-228行)
A*B%  → A*(B/100)        (乘法/除法直接转换 — 第223-224行)  
B%    → (B/100)          (单独百分比 — 第234-237行)
```

**因此本次需求实际上不需要改动 Expression.ets 或 Calculator.ets 的计算逻辑。**

- **理由**：单一领域(UI)，单文件修改。核心计算逻辑已存在，只需增加 1 个按钮 + 1 行点击处理。
